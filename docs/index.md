# DeepSeek Harness 参考

> 🗂 本站是**第三方研究者**整理的 DeepSeek Harness 参考读物，方便自查，也供他人参考。

## 这是什么

DeepSeek Harness（DSH）是 DeepSeek 开源的、模块化、**可插拔**的 Agent 运行 / 开发框架——
把 Agent 拆成零件（模型 / 工具 / Skill / 子代理），再像搭积木一样组装、调度、记忆与回滚。

本站从**研究者视角**整理它的机制、用法与演进，重点是**讲清楚 + 可溯源**，而非官方宣传。
