## 一句话认识它

**DeepSeek Harness（DSH）** 是一个可插拔、模块化的 **Agent 运行 / 开发框架**——
把 Agent 拆成可插拔的零件（模型 / 工具 / Skill / 子代理），再像搭积木一样组装、调度、记忆与回滚。

它最特别的一点：能把 **Codex / Claude Code** 等外部 Agent **收编为子代理**，统一调度。
