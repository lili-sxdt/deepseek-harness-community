# 贡献指南

> 欢迎共建。本站坚持「**小而美、不误导、模板优先**」三原则。

## 本站原则（站规）

1. **小而美**：只做"精选、能立刻行动"的内容，**不做**配置字段百科 / 命令大全 / 大论坛——这些交给官方文档。
2. **不误导**：每个模板/教程**必须标注版本与验证状态**；没实测就写「未实测 · 以官方为准」，**绝不冒充"可用配置"**。
3. **模板优先**：核心价值是"经过验证、直接可复用的模板"，教程是引路，模板是目的地。

## 能贡献什么

| 内容 | 要求 |
| --- | --- |
| **模板** | 实测跑通，并按下方"模板元数据"标注 |
| **案例** | 真实踩坑 + 解法（注明版本 / 报错） |
| **教程修正 / 补充** | 遵循"不误导"，不确定标"以官方为准" |

## 模板提交元数据（必填）

- 用途 / 适用场景
- 难度（入门 / 进阶 / 高级）
- 版本（测过的 harness 版本）
- 依赖条件（模型后端 / docker / GPU 等）
- 复制 → 改 的最小版本与改点
- 输入 / 输出示例
- 已验证日期
- 风险 / 成本说明

## 提交流程

1. Fork 仓库，改好模板 / 文档。
2. 填全上面的模板元数据。
3. 开 PR（Pull Request），注明内容与所测版本。

> 原则：**宁可少、不可错**；看不懂就标「未实测 / 以官方为准」。
