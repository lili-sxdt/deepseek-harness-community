# 贡献指南

> 欢迎共建。本站为社区第三方，内容以「**准确、不误导**」为原则。

## 你能贡献什么

| 内容 | 要求 |
| --- | --- |
| **配置模板** | 只提交你**实测跑通**的 config（多模型 / Agent / 评测 / 压测）——必须标注「适用场景 + 修改要点 + 测过的版本」；**未实测不要上架** |
| **排错案例** | 真实踩坑 + 解法（注明版本与报错） |
| **文档修正 / 补充** | 修正错误、补充说明 |

## 提交流程

1. Fork 仓库，改好你的模板 / 文档。
2. 每个模板加说明：**适用场景、修改要点、测过的版本**。
3. 开 PR（Pull Request），注明内容与所测版本。

> 原则：**宁可少，不可错**。不确定就标「未实测 / 以官方为准」，绝不冒充"可用配置"。
