# FAQ

> 常见疑问与常见坑。按"关系 / 使用 / 排坑"三类归纳。以官方为准。

## 关系类

**Q：DSH 和 Codex / Claude Code 是什么关系？**
A：它们可被 DSH **收编为子代理**，统一调度——这是 DSH 相对独立的定位之一。三者定位不完全重叠，详见[架构](architecture.md)。

**Q：DSH 是官方产品吗？**
A：是 DeepSeek 开源的框架，但本站是**第三方**整理，非官方。

## 使用类

**Q：跨平台支持怎样？**
A：官方提供跨平台运行环境（含 Windows 安全运行时），以官方说明为准。

**Q：会不会很吃资源 / 很贵？**
A：取决于所选模型与任务规模。DSH 通过可插拔模型适配，你可选择不同的模型与配置。以官方文档为准。

**Q：装的东西多吗？**
A：以官方安装方式为准。别全信第三方教程，官方 README 最准。

## 排坑类

**Q：为什么我的子代理没生效？**
A：先确认子代理/编排配置是否符合官方约定，再查日志。这块是相对进阶的能力，见[进阶开发](advanced.md)。

**Q：如何保证结果可复现？**
A：用 DSH 的可复现机制（环境快照、种子、复现包）。详见[进阶开发](advanced.md)。

!!! warning "以官方为准"
    本站仅给出方向性解答，具体命令与行为请以[官方仓库](https://github.com/deepseek-ai/DeepSeek-Harness)为准。
