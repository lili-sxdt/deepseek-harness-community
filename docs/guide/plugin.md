# 插件（Plugin）

> 一句话：**一切皆插件**——模型、工具、技能、子代理、提示词，都能当成可插拔的单元。具体用法以官方为准。

## 什么是"一切皆插件"

DeepSeek-Harness 的**核心理念**：把 Agent 拆成**可插拔的"插件"**。每个能力（接什么模型、用什么工具、调什么技能/子代理、用什么提示词）都是一个**独立可插拔的单元**——想换就换、想加就加，像搭积木。

这也是它区别于"封闭助手"的最大特点：**你不被锁死，所有零件都能换。**

## 有哪些"插件"

| 插件 | 是什么 | 相关页 |
| --- | --- | --- |
| 模型 | 接哪个大模型（DeepSeek / Ollama / vLLM…） | [配置](/config/config-yaml) |
| 工具 | 能调用什么（搜索 / 代码 / API…） | [配置](/config/config-yaml) |
| 技能 Skill | 把某类"怎么做"封装成可复用技能 | [技能](/guide/skill) |
| 子代理 Subagent | 别的 Agent（Codex / Claude Code） | [子代理](/guide/subagent) |
| 提示词 / 角色 | 用什么提示、什么角色 | [自定义 Agent](/guide/custom-agent) |

## 怎么用（最小思路）

1. 把某个能力做成"**插件**"（按官方约定的方式定义 / 注册）。
2. 在配置 / 编排里**指定用哪些插件**。
3. 运行时**按需加载、可插拔替换**（换模型=换一个插件）。

> 🔴 **未实测**：具体插件定义 / 注册 / 加载方式**以官方为准**（这是 Harness 相对独特的机制，我们会随版本校核）。

## 和 Skill / Workflow / Subagent / 自定义 Agent 的关系

它们是"**一切皆插件**"的不同体现：
- **Skill** = 能力插件
- **Workflow** = 编排插件
- **Subagent** = 代理插件（把外部 Agent 收编）
- **自定义 Agent** = 角色插件
