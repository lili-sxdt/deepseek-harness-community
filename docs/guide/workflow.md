# Workflow

> 编排方式：把一次任务拆成多个步骤 / 代理，按"扇出 / 并行 / 流水线"组合完成。**具体写法以官方为准。**

## 它解决什么

- 一个任务不是"一条直线"，而是"几步才能完成"（先 A 再 B，或几件事同时做）。
- Workflow 帮你把这些步骤**按顺序 / 并行 / 条件**编排起来。

## 常见编排模式

| 模式 | 干什么 | 什么时候用 |
| --- | --- | --- |
| **扇出 / 并行** | 多个子任务**同时**跑，再汇总 | 几个独立子任务一起做 |
| **流水线** | 分阶段，上一段的输出给下一段 | 依次处理（如 提取→处理→打分） |
| **分支条件** | 按结果走不同路径 | 需要判断时 |

## 怎么用（最小思路）

1. 把一个任务拆成"步骤"。
2. 定义哪些步骤**并行**、哪些**先后**、哪些**按条件分支**。
3. 跑起来，各子代理/子任务各自完成，最后汇总到一个结果。

> 🔴 **未实测**：具体关键字（agent / parallel / pipeline 等）与字段以官方为准。

## 什么时候用

- 一个任务包含多步、多代理、或可并行的部分。
- 想"一句话触发一整条流水线"。
