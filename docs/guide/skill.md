# Skill

> 可插拔的"能力包/技能"：把某种"怎么做"封装成技能，**按需加载**，而不是常驻。**具体格式以官方为准。**

## 它解决什么

- 你有一套"处理某类任务的方法"，想**复用**、不想每次都重写。
- 把方法做成一个 Skill，用到时加载，用完不占地方。

## 怎么用（最小思路）

1. 把"方法"写成一个 Skill（通常一个 `SKILL.md` 或其他约定的技能文件），里面描述"做什么 + 怎么做"。
2. 在任务里**按需加载**它（框架会按约定读取）。
3. 运行时，你只说一句，它会按 Skill 里写的方法执行。

> 🔴 **未实测**：具体文件名、字段、加载方式随 harness 版本。**以官方文档 / 你实际版本为准**，别照抄这里的示意。

## 最小示例（骨架）

```
# 示例：一个"做 X 任务"的 Skill
- 适用场景：……
- 做法：Step 1 … Step 2 … Step 3 …
- 注意：……
```

## 什么时候用

- 有可复用方法的任务（评测、数据处理、某种分析）。
- 想保持"方法"与"主流程"解耦。
