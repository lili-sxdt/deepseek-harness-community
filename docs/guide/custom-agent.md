# 自定义 Agent & 预设

> 一句话：定义"某类任务由某角色来做"，把角色做成**预设**、或自己**自定义预设**。具体做法以官方为准。

## 什么是 Agent 预设 / 预设

- **Agent 预设**：一个**预制好的 Agent 角色 / 模板**，你直接拿来用（"谁来干某类活"）。
- 预设的好处：**角色、职责、行为约定都封装好**，要哪类任务就用哪个角色，不用每次重定义。

## 常见预设示例

> 以下为角色类型示例，具体预设名与含义**以你实际版本 / 配置为准**。

| 预设 | 干什么 |
| --- | --- |
| 综合 / 总指挥 | 统筹整个任务 |
| 文献 / 检索 | 搜集、汇总资料 |
| 分析 | 数据处理、统计、出结论 |
| 写作 | 产出内容 / 报告 |
| 审查 / 审计 | 复核、挑毛病、把关 |

> 较高阶还有"**抽象角色**"：比如"审计官"（独立裁决）、"执行员"（并行干活）、"仲裁员"（汇总裁决）——用于**质量把关 / 多代理协作**。

## 自定义预设（怎么定义你自己的）

1. 给这个 Agent 一个**名称 + 职责 + 行为约定**（想清楚它"是谁、干什么、怎么做"）。
2. 按官方方式把它定义成预设（保存为一个角色 / 模板）。
3. 任务里**指定用哪个预设 / 角色**，它就按该角色的约定执行。

> 🔴 **未实测**：预设定义格式、存储方式、调用约定**以官方为准**。

## 和插件 / 子代理的关系

- 它是"**一切皆插件**"里的一种**角色插件**（见[插件](/guide/plugin)）。
- 预设侧重"**定义角色**"；子代理侧重"**收编外部 Agent**"（见[子代理](/guide/subagent)）。
- 想按角色干活 → 预设；想把外部 Agent 变成手下 → 子代理。
