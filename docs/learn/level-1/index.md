# 认知上手 · 开课导览

> 这一课带**完全没接触过 AI 助手的人**，走完最重要的一步：**从"这是什么"到"我会用了"。**

## 这门课要带你去哪

学完这一课，你会做到三件事：

1. **能说清**"AI 聊天"和"AI 助手"到底差在哪——一句话讲给外行听。
2. **亲手装好** DeepSeek Harness，并**跑通**第一个最简单的例子。
3. **派一件真实的小活**，并学会**检查它交来的成果**。

到那时你就从"听说过 AI 助手"，变成了**真的用上它**。

## 这门课不适合谁

如果你已经知道"AI 助手是帮你做事、你要验收的那种东西"，可以直接跳到第二课「概念运用」。

## 该怎么学

- 顺着页码往下走就行，**不要跳**。每一步都是下一步的地基。
- 看到「跟着做」就**真的动手做**——这门课光看是学不会的。
- 卡住了别慌，每步都写了「对不对的样子」和「救急办法」。

## 这一课的目录

| 小站 | 学什么 |
|---|---|
| 认识助手 | 聊天 vs 助手，一句话就懂 |
| 快速装通 | 下载、安装、跑通第一个 |
| 动手实战 | 派一件真实小活 + 验收 |
| 出师检验 | 做完这几题，这门课你就过了 |

## 一句话记住这门课

> **AI 助手不是"聊天框"，而是"会帮你做一件事、再把成果交给你看"的那个东西。**
