# 出师检验：做完这几题，你就过了

> 这一关**不看我上面的步骤**，你自己独立完成。做出来，才算真正学完第一课。

## 检验一：能不能讲清楚？

**用你自己的话**，对你完全不了解 AI 的朋友说清楚"AI 聊天"和"AI 助手"的区别。**不看上面的页，说给外行听懂**就算过。

> 你自己的话应该抓到这一点：**聊天是"答你"，助手是"帮你做一件事、再交给你看"。**

## 检验二：能不能装好、跑通？

**从头自己走一遍**：装好 Node → 跑**一条命令** `npx @deepseek-ai/dsh web` → 访问 `http://127.0.0.1:3080/` 看到界面。

- 完成，说明"安装 + 跑通"真的会了。
- 想更可控（源码/自己带模型），可改用[快速装通](/learn/level-1/install-and-run)里的**路 B · 源码 + Docker**。
- 卡住，回[快速装通](/learn/level-1/install-and-run)看救急，再试。

## 检验三：能不能派活 + 验收？

**不看我上面写的**，自己挑一份文件，给 DSH 下一个"提炼要点"的指令，然后**检查它交的成果**。问自己三句：做了我要求的事吗？全吗？方向对吗？

- 三句都对，说明你**会派活、也会验收**——第一课毕业水平达标。

## 出师标准一览

| 检验 | 达标 = 你已能 | 对应子站 |
|---|---|---|
| 检验一 | 一句话讲清聊天 vs 助手 | 认识助手 |
| 检验二 | 下载、安装、跑通 | 快速装通 |
| 检验三 | 派真实小活 + 验收成果 | 动手实战 |

三道都做到，**第一课「认知上手」你就过了**。✅
