# 动手实战：派一件真实小活

> 现在真正"用"它一次。**跟着做**，这次是让你体会"派活 → 验收"这条线。

## 任务：提炼一份文档的要点

选一份你电脑里的文本文件（比如一份调研笔记、一份旧报告），让 DSH 把它提炼成一页。

## 第 1 步：把话说清楚（关键！）

给助手下指令，一定要说清**做什么、做到什么程度、结果放哪儿**。

❌ **这样下指令**（太模糊，它不知道你要什么）：
```
帮我看看这个文件。
```

✅ **这样下指令**：
```
请阅读 D:\资料\调研.txt，
把里面关于"N 管理"的要点提炼成一段 300 字以内的总结，
保存到 D:\资料\总结.txt。
```

> 一句话自查：你的指令里，**"做什么""做到什么程度""结果放哪"** 都说了吗？说清了，它就不容易做偏。

## 第 2 步：让它去做，你等它交活

它会先告诉你"打算怎么做"，然后开始读文件、整理。这段你不用管。

## 第 3 步：验收（这步最重要）

拿到成果后，**别直接信**。花一分钟问自己三句：

1. **它做了我要求的事吗？** 还是自己跑了偏？
2. **做得全吗？** 有没有漏掉关键点？
3. **方向对吗？** 有没有理解错、甚至胡说？

发现不对，就像带实习生一样回它：
```
总结里漏了"N 比例"这一块，请补上。
```
它会回去重做。

## 你现在体验到的"助手"

它**读了文件、做了事、交了成果**，并且你**必须验收**——对了用，不对打回。这正是第一课说的"AI 助手"：**有任务、有交付、有验收。**

## 更多可以做的实例（任选一个，都练"派活→验收"）

把下面任何一个当练习，都能巩固这一课：

**实例 ①：文档要点**（上面刚做的）
```
请读 D:\资料\会议记录.docx，把这 5 个议题各用一句话总结，保存为 会议要点.txt。
```

**实例 ②：表格转报告**
```
请读 D:\资料\销售表.xlsx，按"季度"统计总额，生成一段 200 字以内的说明，存到 D:\资料\季度小结.txt。
```

**实例 ③：批量算指标**
```
请读 D:\试验\数据.csv，计算每组的平均值和标准差，输出一张表格保存到 D:\试验\结果表.xlsx。
```

**实例 ④：翻译 + 排版**
```
请把 D:\资料\介绍.pdf 的引言翻成中文，保留原文小标题层级，保存为 D:\资料\引言-中文.md。
```

> 挑一个你最贴近工作的，把它做一遍。**关键不是做得多复杂，而是体会"我说清楚 → 它干 → 我验收"这个闭环。**

## 动手实战小结

| 你刚做的 | 对应"助手"的特性 |
|---|---|
| 说清做什么 | 任务要具体 |
| 让读文件、生成总结 | 它会用工具动文件 |
| 拿到成果先检查 | 交付后要验收 |
| 说"再改一下" | 能迭代、回退 |

## 做完这步，你的得分

你已能 **亲手派一件活、并验收一份成果**——第一课讲的"会用"，你已经做到了。

接着走 → **出师检验**。
