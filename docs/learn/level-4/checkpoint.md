# 出师检验：做完这几题，你就到"精通"了

> 最后一关。**不看我上面的页**，独立完成才算过。

## 检验一：能不能说清？（理解）

用你自己的话讲清：`skill` 和 `plugin` 的区别。
抓住"**skill 是教它怎么干，plugin 是让它多出一样本事**"就算过。

## 检验二：能不能看懂结构？（理解）

在 DSH 里找到它的插件位置/一个现成 plugin，说出"它接在哪儿、长什么样"。能说出"每个 plugin 都接在约定位置、有固定格式"就算过。

## 检验三：毕业项目达成（能力）

把你[毕业项目](/learn/level-4/project)里做的那个 plugin，在你**真实工作**里用它一次，确认它解决了你的那个痛处。

- 解决了 → 通过（你真做到了"开发自己工作的使用人员"）
- 没解决 → 回到具体那步修，再用

## 出师标准一览

| 检验 | 达标 = 你已能 |
|---|---|
| 检验一 | 讲清 skill vs plugin |
| 检验二 | 看懂 DSH 结构，知道往哪儿加能力 |
| 检验三 | 加了一个为自己的活服务的能力并真用上 |

三题都做到，**第四课「框架扩展」你就过了，整站也通关了**。🎉

## 恭喜通关 🎉

你走完了从"完全不懂"到"把 DSH 调教成自己工作一部分"的完整路。回头看：

- **第一课** 会用 → **第二课** 会看懂、会用对 → **第三课** 会用它做东西 → **第四课** 会把它改成合自己用的。

**从入门到精通，你已经走完了。**
