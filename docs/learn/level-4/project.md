# 毕业项目：把你工作的需要，做成 DSH 里一个真能力

> 这是整站的**收官**。前三课学的（会用、看懂、用 DSH 做东西）+ 这一课学的（扩展 DSH 本身），在这里合起来。做完它，你就走完"从入门到精通"了。

## 这个项目要做什么

> **找出你工作里一个 DSH 现在"做不到"或"做不好"的具体需要，写一个 plugin，让它变成能用的能力。**

它必须**是为你的活服务**的，不是随便做一个来交差。

## 怎么做（四步）

### 第 1 步：找一个"你的痛处"

想想你的工作里，有没有这种事：**每次都要手动做、很烦、DSH 又没现成功能。** 就挑它。

例子：
- "我每次都要把结果导出成我们组的固定表头"
- "我每次都手动给报告加一段固定说明"
- "我常用的一个工具 DSH 没接上"

### 第 2 步：把它拆成一个"小能力"

不要贪大，只做**一个**最具体的能力。比如上面第三个例子 → "让 DSH 能调用我这个工具"。

### 第 3 步：写这个 plugin

按[插件开发](/learn/level-4/plugin)学过的方法：
1. **先看现成 plugin**，照着骨架。
2. 写你的——它做什么、怎么接入、输出什么。
3. 放对位置。

### 第 4 步：让它真的跑通并服务于你

在你的**真实工作**里用它一次，确认它真的解决了你的那个痛处。

✅ **做成了的样子**：你工作中那件烦事，现在 DSH 能帮你做了。
❌ **没跑通**：回到具体那步排查（位置/接入/写法），别急着换别的。

## 你走完了整条路

| 课 | 你到了哪 |
|---|---|
| 第一课 | 会用 DSH |
| 第二课 | 看懂 DSH、会用对 |
| 第三课 | 用 DSH 做自己的东西 |
| 第四课 | 把 DSH 改成合自己用的，加一个真能力 |

**这就是"从入门到精通"的完整闭环**——你已经不是一个"用工具的人"，而是"**能把工具调教成自己工作一部分的人**"。

## 一个温柔提醒

DSH 迭代快，**你的 plugin 可能随版本要小调。** 学会"读现成 + 对照[版本页](/version-status)"，就能自己维护它——这也是"精通"的一部分。
