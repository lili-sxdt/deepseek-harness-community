# 动手实战：实际搭一个能跑的小东西

> 这一关是把前面三页（skill、workflow/pipeline、agent 编排）串起来，**跟着做**，搭一个能跑通的小系统。

## 任务：搭一个"一键出周报"的小流程

场景：你每周要写一份周报。目标是搭一个小流程，让 DSH 帮你**自动**完成"汇总本周工作 → 套用格式 → 生成周报"。

## 第 1 步：先拆成几步

这一步是"规划"——想清楚要几步、谁先谁后：

```
① 汇总本周工作数据   →  ② 套用固定格式   →  ③ 生成一份周报
```

## 第 2 步：为"格式"写一个 skill

用你[上一课](/learn/level-3/skill)学的，写一个 `week-report-style` 的 skill，规定周报的标题、分块、落款格式。

## 第 3 步：为"三步"串一条 pipeline

把上面三步，连成一条流水线——**前一步的输出，喂给下一步**。

```
汇总(①) ──► 套格式(②) ──► 生成周报(③)
```

## 第 4 步：跑通它

让它跑一遍，看它是不是：
- 真的从"汇总"到"生成了周报"一路跑通？
- 生成的周报，**真的套用了你写的格式**？

✅ **做对了的样子**：一键跑完，周报生成且格式是对的。
❌ **卡住了**：哪一步断了，回到那一步看；格式不对，回`week-report-style` 那个 skill 检查你写的规则。

## 你做到了什么

你**自己规划、自己写 skill、自己串 pipeline，让它跑通了一个小流程**——从"用 DSH"走到了"**用 DSH 做你的活**"。✅

## 再做一版：换个场景再搭一个

刚才搭的是"周报"。再挑下面一个，重复"拆步 → 写 skill → 串 pipeline → 跑通"这套动作：

**换一个a：一批文件夹整理**
```
读入文件夹 → 按规则分类 → 移到对应子目录
```

**换一个b：一个数据出多张图**
```
读入数据 → 算指标 → 生成 3 张图 → 汇总成一段说明
```

> 关键：**每一版都坚持"从最小能跑开始"**——先让两三步跑通，再往前加。

## 一个提醒

**从最小能跑的开始。** 别一上来就做很复杂的流程。先做"三步出周报"这种，跑通了，再往上加。

接着走 → **出师检验**。
