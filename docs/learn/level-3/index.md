# 应用构建 · 开课导览

> 你已在第一课"会用"、第二课"看懂"，这一课带你**在 DSH 的框架里做出自己的东西**——但**不碰 DSH 本身**。这是"使用人员"往上一步，开始为自己的工作定制。

## 这门课要带你去哪

学完这一课，你会**亲手**做出三样东西：

1. **写一个自己的 `skill`**——一张给助手照着做的"作业说明书"。
2. **串一条 `workflow` / `pipeline`**——让几个步骤连起来跑，或一次扇出很多再收回。
3. **编排 `agent`**——让几个助手分工，拼成一个大任务。

## 先说清楚：这门课"碰"在哪、不"碰"哪

- **你碰**：在 DSH 的框架里**搭东西**（写 skill、串 workflow、编排 agent）。
- **你不碰**：DSH 框架**本体**（它的核心代码、怎么扩展）。

> 这就像**盖房子**——用已经准备好的材料（skill/workflow/agent），把房子盖起来。**至于"改进造房子的工具"**，那是第四课「框架扩展」的事。

## 这套比喻继续用

第二课的"工作室"到这里活起来了：
- `skill` = 你给某个岗位写的**作业手册**
- `workflow`/`pipeline` = 你把几件事**连成流水线**、或一次**派很多外包再收回**
- `agent` 编排 = 你让几个员工**分工**拼成一个大活

## 这一课的目录

| 小站 | 学什么 |
|---|---|
| 构建总览 | 在框架里"搭东西"的整体观 |
| 编写技能 | 写一个自己的 skill |
| 流程编排 | 串一条 workflow / pipeline |
| 动手实战 | 实际搭一个能跑的小东西 |
| 出师检验 | 做完这几题，你会"用 DSH 做东西"了 |

## 一句话记住这门课

> **这一课，你是"盖房子"的人——用 DSH 现成的材料，盖出你自己要的东西。**
