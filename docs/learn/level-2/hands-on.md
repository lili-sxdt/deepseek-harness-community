# 动手实战：给一个真实场景画分工图

> 这一关不是让你背名词，而是**用**你刚学的分工表。跟着做。

## 任务：给"帮我查文献"这个场景，画一张分工图

场景：你让 DSH"把某主题的文献查一遍、去重、整理成一份文献库"。现在请你判断：**这件事会用到里面的哪些角色，各干什么？**

## 第 1 步：先拆，这个任务要几步

先从大到小拆一下，它大概是这样几步：
1. 按主题去多库检索
2. 去掉重复的
3. 整理成一份文献库（比如 BibTeX）

## 第 2 步：对号入座，该用哪个

| 任务 | 该用谁 | 因为 |
|---|---|---|
| 检索 | `skill`（文献检索手册） | 需要"按什么标准/怎么做"的套路 |
| 去重、入库 | 主对话让一个 **agent** 做 | 一件连贯的活，直接做 |
| 想一次并行查好几个库 | **workflow** / 多个 **subagent** | 多件独立任务，扇出去再收回 |
| 让它长期都这么干 | 写进 **AGENTS.md** | 想让它长期守这套流程 |

## 第 3 步：画出来

把你选的答案，填进这张图：

```
【查文献任务】
  ├─ ① 检索     → 用 ______（因为它给"怎么检索"的标准）
  ├─ ② 去重入库  → 让 ______ 直接做
  ├─ ③ 多库并行  → 用 ______（一次扇出很多再收回）
  └─ ④ 长期这么干 → 写进 ______
```

> 参考答案：① skill　② agent　③ workflow / 多个 subagent　④ AGENTS.md

## 第 4 步：检查画得对不对

对照[选型决策](/learn/level-2/choose)那张表，看你每一步选的是不是**最贴**的那个。**能说清"为什么选它"，比选对更重要。**

## 你做到了什么

你不再是"认识名词"，而是**能根据一件具体的事，选出该用哪个**——这正是第二课"**会用对**"的核心。✅
