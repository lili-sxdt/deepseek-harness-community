# 出师检验：做完这几题，你就"懂 + 会用对"了

> 这一关**不看我上面的页**，独立完成才算过。

## 检验一：能不能讲清楚？（理解）

任选 **4 个**名词（`AGENTS.md`、`skill`、`subagent`、`subagent_fork`、`workflow`、`pipeline`、`plugin`），用**自己的话**给一个外行讲清它是什么。不看上面的页，讲得让外行懂就算过。

## 检验二：能不能选对？（应用）

下面三件事，各该用哪个？选完说出理由。

1. 你刚做完一次分析，要**独立检查**结果有没有错 → 该用 ______
2. 想让它**接着上次的对话**继续往下做 → 该用 ______
3. 想让助手**每次都**把产物放到指定目录 → 该用 ______

> 参考答案：① 全新上下文的 `subagent`（独立客观，禁止 self-check）　② `subagent_fork`（继承旧上下文）　③ 写进 `AGENTS.md`（长期生效）。

## 出师标准一览

| 检验 | 达标 = 你已能 |
|---|---|
| 检验一 | 能用大白话讲清 4 个核心名词 |
| 检验二 | 面对具体任务，能选对并说出理由 |

两题都做到，**第二课「概念运用」你就过了**。✅
