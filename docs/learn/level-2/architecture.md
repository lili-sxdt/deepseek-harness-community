# 架构总览：一张图，把 7 个名词对号入座

> 先看这张图，**别背**。把它当成一家工作室，每个名词都对上号。

## 一家工作室长这样

```
                    ┌────────────────────────────┐
                    │   你（老板 / 派活的人）        │
                    └──────────────┬─────────────┘
                                   │ 你说的话 = prompt
                                   ▼
   ┌─────────────────────────────────────────────────────────────┐
   │                    一所工作室（DSH）                          │
   │                                                             │
   │  ┌─────────────────────────────────────────────────────┐   │
   │  │  AGENTS.md = 公司章程 / 岗位职责                       │   │
   │  │  「每次开会自动放桌上，人人默认遵守」                    │   │
   │  └─────────────────────────────────────────────────────┘   │
   │                                                             │
   │  ┌────────────┐       ┌────────────┐                        │
   │  │  agent     │       │  agent     │                        │
   │  │  员工本人    │       │  员工本人    │                        │
   │  └────────────┘       └────────────┘                        │
   │        │                      │                              │
   │        │ 翻作业手册            │ 派外聘外包                     │
   │        ▼                      ▼                             │
   │  ┌──────────────┐       ┌──────────────┐                    │
   │  │ skill        │       │ subagent     │                    │
   │  │ 作业手册      │       │ 外包/新员工    │                    │
   │  └──────────────┘       └──────────────┘                    │
   │        │ 上流水线             │ 一次扇出很多                   │
   │        ▼                      ▼                             │
   │  ┌──────────────┐       ┌──────────────┐                    │
   │  │ pipeline     │       │ workflow     │                    │
   │  │ 流水线(工序)  │       │ 项目经理调度  │                    │
   │  └──────────────┘       └──────────────┘                    │
   │                                                             │
   │  ┌────────────────────────────────────────────────────┐    │
   │  │ plugin = 可插拔的零件（缺哪补哪，补完马上能用）        │    │
   │  └────────────────────────────────────────────────────┘    │
   └─────────────────────────────────────────────────────────────┘
```

## 只看懂三根线

1. **AGENTS.md 在最上面**——它是大家默认遵守的"共同规矩"。
2. **agent（员工）干活时**，会**翻 skill**（作业手册）来做事；也能**雇 subagent**（外包）去独立办一件事；还能让 **workflow** 一次扇出很多外包。
3. **pipeline** 是把几件事连成工序；**plugin** 是随时能插拔的零件。

## 一页速查（贴墙版）

| 名字 | 一句话 | 打比方 |
|---|---|---|
| prompt | 你写的指令 | 对员工说的话 |
| agent | 正在干活的那个助手 | 员工 |
| AGENTS.md | 每次自动加载的常驻规矩 | 公司章程 |
| skill | 按需加载的操作标准 | 作业手册 |
| subagent | 全新上下文的子助手 | 外包 / 新员工 |
| workflow | 一次扇出很多任务再汇总 | 项目经理调度 |
| pipeline | 有固定顺序的工序 | 工厂流水线 |
| plugin | 可插拔、即时生效的扩展 | 乐高零件 |
