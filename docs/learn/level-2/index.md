# 概念运用 · 开课导览

> 你已经在第一课"会用" DSH 了。这一课带你**看懂它**——为什么会有 `AGENTS.md`、`skill`、`subagent`、`workflow`、`pipeline`、`plugin` 这些名词，它们到底各是干嘛的。

## 这门课要带你去哪

学完这一课，你会做到两件事：

1. **理解**：把这几个名词，用"一家工作室"的比方一次性对号入座，不再懵。
2. **应用**：遇到一件具体的事，你能**选对该用哪个**。

## 这套比喻，全站通用

> **把 DSH 想成一家做研究的工作室。** 里面有用的人、有公司章程、有各岗位的作业手册、有外包临时工、有项目经理、有流水线、有可插拔的零件。

这套比喻第一课用了一点（助手=实习生），这一课把它铺开，后面两课继续用。**记住它，三课就串起来了。**

## 一句话记住这门课

> **这些名词不是一堆孤立术语，而是一家"工作室"里各自的角色——你只是要认清"谁负责什么"。**
