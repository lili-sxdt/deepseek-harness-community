# 进阶开发

> 由浅入深：从「会用」到「会扩展」。以官方文档为准，这里讲清概念与方向。

## 插件开发

- **什么是插件**：DSH 里一切皆插件——模型、工具、提示词、Skill、子代理都可作为可插拔单元。
- **接口约定**：插件的注册、生命周期与调用约定（以官方插件指南为准）。
- **与 Skill 的区别**：

| | 插件 | Skill |
|---|---|---|
| 粒度 | 更底层 / 可插拔 | 按环节加载的能力包（SKILL.md） |
| 作用 | 扩展框架能力 | 提供"怎么做"的方法论 |

## 子代理与工作流

- **子代理**：能把 Claude Code、Codex 等**收编**为可调度的子代理，统一编排。
- **编排模式**：一对多扇出、并行执行、汇聚结果。

| 模式 | 用途 |
|---|---|
| agent（单任务） | 委派一个自包含子任务 |
| parallel（并行） | 多个独立任务同时跑 |
| pipeline（流水线） | 分阶段、可跨段传递结果 |

## 模型与提供商适配

- DSH 通过可插拔方式接不同 LLM 提供商，可在不同模型之间切换。
- 关注官方对多模型 / 提供商适配的支持方式。

## 可复现与审计

- **可复现**：环境快照、数据与代码、随机种子、复现包（REPRODUCE）。
- **审计**：产物经独立审计判断（PASS / CONDITIONAL / FAIL），非自审。
