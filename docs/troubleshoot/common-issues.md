# 常见问题排查

> 把高频坑按类整理。**先看这里，再提问。** 若与你版本不符，留意[版本状态](/version-status)。

## 安装依赖报错

- **npm/pnpm 镜像慢**：换镜像源（`npmmirror` 等）。
- **Python 版本冲突**：确认要求的版本，用虚拟环境（venv/conda）。
- **编译问题**：某些依赖需要编译工具链，按报错装对应依赖。

## 模型连接失败

- **超时**：增大超时，或检查模型端点本地是否可达。
- **鉴权**：确认 `api_key` 正确、且用环境变量而非明文。
- **后端接口兼容**：确认 provider / base_url 与你用的模型服务匹配。

## Agent 运行异常

- **工具调用失败**：检查工具名/参数是否被正确注册。
- **循环卡死**：设 `loop.max_iter` 上限。
- **输出解析错误**：检查输出格式与解析器约定是否一致。

## 性能问题

- **并发高卡顿**：降并发，或先小批量验证。
- **显存 OOM**：减小 batch / 上下文窗口，或用更小模型。
- **吞吐量低**：调并发、batch、重试/超时参数。

## 版本迁移

- 升级 harness 后配置可能不兼容（字段改名 / 行为变化）。
- 看[版本状态](/version-status)的迁移说明；老配置先备份再升。

## 错误速查表

> 持续补充。遇到常见错误码/报错文案，欢迎回填。

| 错误 | 可能原因 | 处理 |
| --- | --- | --- |
| connection timeout | 模型端点不可达 | 检查服务+网络+超时 |
| unauthorized | api_key 错误 | 改环境变量 |
| OOM | batch 过大 | 减小 batch |
