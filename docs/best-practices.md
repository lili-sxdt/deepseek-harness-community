# 最佳实践

> 基于经验的建议，帮你少踩坑、实验可复现。具体以官方为准。

## 密钥与安全

- **密钥一律用环境变量**注入（`${API_KEY}` 或读取 shell 环境变量），**绝不明文写入配置文件**。
- 配置 / 仓库**不放任何 API Key、模型权重**。

## 可复现实验

- 记录**随机种子、依赖版本、数据快照、完整配置**。
- 结果输出到固定目录（`storage.out_dir`），便于回溯与对比。
- 记录你**测过的版本**（见[版本列表](/version-status)），旧配置别套新代码。

## 本地 vs 生产

- **本地**：先用小批量、最小配置验证。
- **生产**：注意并发、超时、日志（`log_level`）、遥测（隐私，可关闭 `telemetry: false`）。

## 显存 / 并发 / 选型

- **显存吃紧**：减小 batch / 上下文窗口，或用更小模型。
- **并发高卡顿**：先小并发验证，再逐步加。
- **模型选型**：按任务（文本 / 代码 / 多模态 / Agent）选合适的适配器。

## 版本与升级

- 升级前**先备份**旧配置，参考[版本列表](/version-status)的迁移说明。
- 每个配置标注**测过的版本**，避免"旧配置套新代码"。

## 排错优先

- 遇到报错先看[故障排查](/troubleshoot/common-issues)，减少反复试错。
