# 首页 · 一句话定位（Hero）

**DSH 是什么**：一个可插拔、模块化的 Agent 运行 / 开发框架——把 Agent 拆成零件，再还给开发者。

::: step
- **一切皆插件** —— 模型、工具、提示词、Skill、子代理都能热插拔
- **子代理编排** —— 把 Claude Code、Codex 收编成可调度的子代理
- **跨工具 Agent** —— 一套统一调度，跨模型、跨工具、跨环境
:::

::: takeaway
一句话钩子：不是又一个命令行工具，而是「搭积木一样组装 Agent」的框架。
:::

**子代理吸收**

# 快速开始 · 五分钟上手

**安装**：三条命令以内跑起来。

::: step
- **Step 1** — 安装运行环境（Windows / macOS / Linux）

# 开发文档 · 六大模块

- **架构设计** —— 分层（框架 / 插件 / 模型-工具 / 工作区）与数据流
- **插件开发指南** —— 接口约定、生命周期、注册方式、与 Skill 区别
- **子代理与工作流** —— 一对多扇出、并行、结构化结果（agent / parallel / pipeline）
- **模型与提供商适配** —— 如何接不同 LLM
- **工作区与持久化** —— 仓库 / 上下文 / 状态记忆，以及回滚怎么做
- **可复现与审计** —— 复现包、复现命令、独立审计

# MVP 优先级 · 先做这三件

::: step
- **第 1 件** — 首页 + 特性 + 快速开始 + 文档（满足「来了能用」）
- **第 2 件** — 一组真实案例 + before/after（满足「看了想用」）
- **第 3 件** — 插件 showcase + 贡献入口（满足「用了愿意回」）
:::
